# Mediary — видеоплатформа с персональной видеотекой

Веб-платформа для хранения, организации, публикации и просмотра видеоконтента с использованием искусственного интеллекта для анализа видео.

## О проекте

Проект разрабатывается в рамках курсовой работы.

Основная идея — объединить функциональность видеохостинга и персонального облачного хранилища. Пользователи смогут создавать собственные видеотеки, управлять доступом к видео, взаимодействовать с другими пользователями и получать персональные рекомендации.

## Основной функционал

- Регистрация и авторизация пользователей
- Личный профиль и видеотека
- Загрузка, просмотр и удаление видео
- Создание коллекций и плейлистов
- Настройка доступа к видео (публичный, приватный, ограниченный)
- Поиск видео по категориям и тегам
- Лайки, комментарии и подписки
- История просмотров
- Персональные рекомендации

## Возможности искусственного интеллекта

- Автоматическое распознавание речи
- Генерация субтитров
- Перевод субтитров на другие языки
- Анализ содержания видео
- Улучшение поиска и рекомендаций

## Архитектура

Проект планируется реализовать с использованием микросервисной архитектуры.

Основные сервисы:

| Микросервис | Назначение |
|---|---|
| Auth Service | Регистрация и авторизация |
| User Service | Управление профилями |
| Video Service | Управление видеоконтентом |
| Processing Service | Обработка видео и субтитров |
| Search Service | Поиск видео |
| Recommendation Service | Персональные рекомендации |
| Interaction Service | Лайки, комментарии и подписки |
| Notification Service | Уведомления |

Взаимодействие между фронтендом и бэкендом планируется организовать через REST API и API Gateway.
