# Mediary

Mediary объединяет личную видеотеку, публичный каталог и студию автора. Веб-интерфейс использует React, серверная часть — Java 17 и Spring Boot.

## Локальный запуск

Из корня проекта выполните:

```sh
docker compose up -d --build
docker compose ps
```

Откройте http://localhost:8088. Зарегистрируйтесь через личный кабинет. Для проверки приглашений создайте второй аккаунт в другом профиле браузера. При загрузке выберите «По приглашению» и укажите зрителя. Ссылку на ролик можно скопировать из адресной строки плеера.

Для остановки выполните `docker compose down`. Именованные тома сохраняют базу, видео и журнал Kafka. Пароль PostgreSQL можно задать переменной окружения `DB_PASSWORD` до создания тома базы.

## Компоненты

| Контейнер | Назначение |
| --- | --- |
| web | Nginx раздаёт Vite-сборку и проксирует HTTP API и HLS |
| api | Аккаунты, cookie-сессии, каталог с контролем доступа, публикация видео, подборки, история и статистика |
| processor | Забирает задания из PostgreSQL, создаёт версию MP4 до 480p через FFmpeg и очищает удалённые файлы |
| notifications | Читает transactional outbox, публикует события в Kafka и сохраняет уведомления с дедупликацией по ID |
| live | MediaMTX принимает RTMP от автора и отдаёт эфир через HLS |
| db, kafka | PostgreSQL и одноузловой Kafka в режиме KRaft |

Java-процессы используют общий Maven-модуль и общую схему PostgreSQL. Метаданные личной библиотеки хранятся в JSONB с проверкой версии при сохранении. Медиафайлы находятся в томе `media`. Поиск и ранжирование рекомендаций выполняет клиент по каталогу, доступному текущему пользователю. Смена прав доступа применяется также к запросам диапазонов байтов и к версии 480p.

## Прямой эфир

В разделе «Прямые эфиры» откройте настройки OBS. Скопируйте сервер RTMP и ключ трансляции в OBS и начните вещание. Зритель выбирает канал в том же разделе. Чат хранит сообщения в PostgreSQL и обновляется при просмотре эфира.

## Проверки

```sh
mvn -f backend/pom.xml clean verify
cd frontend
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
pnpm run build
```

Студия считает просмотр при начале воспроизведения, показывает просмотры и число уникальных зрителей за день. Экран ИИ сохраняет демонстрационные данные исходного интерфейса.
